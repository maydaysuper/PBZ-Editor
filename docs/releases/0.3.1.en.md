# v0.3.1 · Soul clear only while the category is editable

[简体中文](0.3.1.zh-CN.md)

This build keeps the v0.3.0 compatibility checks and does not relax main-weapon writes. A numeric layout the editor cannot confirm stays view-only, so it does not write a structure the game may reject.

- When a main weapon or phantom weapon **is still editable**: remove it from the backpack and add it back in the same edit. On save, `AlreadySnapSoul` is written as unforged (`0` for a main weapon). Changing the strengthen level alone does not clear an existing soul forge.
- If the UI shows 「部分功能仅可查看：主武器」 or 「该类别的数值结构已变化，仅可查看。」, this build **still refuses weapon writes** on purpose.
- The remove-and-add soul clear therefore runs only when that category is editable. A view-only main weapon is not written.
- Exit the game before editing, and back up the save first. The editor also creates an automatic backup before it writes.

**Download `PBZ-Editor-0.3.1-windows-x64.zip`, extract it completely, exit the game, and run `PBZ-Editor.exe`.** Default settings and backups are retained. Keep `.local` when upgrading a portable installation.
