# v0.3.2 · Clear soul forge while the category stays view-only

[简体中文](0.3.2.zh-CN.md)

This build still does not relax add, edit, or remove for main weapons. A numeric layout the editor cannot confirm stays view-only, so it does not write a structure the game may reject.

- **Clear soul** is available when a forged main weapon or phantom weapon is selected in the inventory, including when the UI shows 「部分功能仅可查看：主武器」 or 「该类别的数值结构已变化，仅可查看。」.
- On save, the only field written is `AlreadySnapSoul`: integer `0` for a main weapon, boolean `false` for a phantom weapon. The item stays in the inventory. Level, timestamps, and every other field stay as they were.
- **Remove** stays disabled when that category is not editable.
- Exit the game before editing. The editor also creates an automatic backup before it writes.

**Download `PBZ-Editor-0.3.2-windows-x64.zip`, extract it completely, exit the game, and run `PBZ-Editor.exe`.** Default settings and backups are retained. Keep `.local` when upgrading a portable installation.
