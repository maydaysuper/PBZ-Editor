# v0.3.6 · Let Zhang finish the hand-in in the game

[简体中文](0.3.6.zh-CN.md)

The achievement list does not follow an `UnlockedIds` edit. v0.3.4 marked the delivery branch finished, so Quick Hand Zhang no longer runs the game's own hand-in, and Steam never unlocks Lost and Found.

The two **More** actions now prepare the hand-in. They do not write `ACH_039` and they do not grant the reward:

- **Village of Lu: let Zhang take the hand-in**
- **Mirage Estate: let Zhang take the hand-in**

Using either item again on a chapter that is already delivered sets that chapter's delivery branch back to in progress (`BranchActivating`) and removes it from the completed list. The collection branch and the "treasures collected" tags stay. Crimson Forest, Pangzhen, and Meigu Lake are not rewritten.

Save, exit completely, and load the game. Talk to Quick Hand Zhang at **that region's hideout** (the cave behind the bell). The delivery should be available. The game finishes the chapter and gives the reward. If the other regions are already delivered, the game unlocks Lost and Found. Whether the conversation opens was not verified on a live game here.

**Download `PBZ-Editor-0.3.6-windows-x64.zip`, extract it completely, exit the game, and run `PBZ-Editor.exe`.**
