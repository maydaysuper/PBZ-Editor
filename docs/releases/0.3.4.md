# v0.3.4 · 完成陆家村和戏梦山庄的妙手空空

「更多」里新增两项。它们只改这两段已经对上的存档字段，不放开只读类别，也不改清除铸魂。

- **完成陆家村的妙手空空**：把任务 `MiaoShouKongKong` 的分支 `3` 和 `3-1` 标成已完成，补上 `ljc.小张收集物.1/2/3` 和 `ljc.藏身处小张.收集完奇珍异宝`。饰品可写、背包里还没有细线球时，补上 `AC_Control`。
- **完成戏梦山庄的妙手空空**：同样处理分支 `6` 和 `6-1`，标记前缀是 `xm`（与铃铛 `bell_xm_xiao_zhang_005` 一致）。缺少月雷华灯时补上 `AC_Electrified`。
- 五个区域的分支都完成时，才把成就 `ACH_039`（妙手拾遗）加进 `__Achievements__.UnlockedIds`。只完成这两段不会改成就槽。Steam 弹窗要游戏自己上报，读档不一定弹出。
- 珍宝仍留在背包里。改动先留在预览，点保存才写入，写入前自动备份。任务记录对不上时不写。

**下载 `PBZ-Editor-0.3.4-windows-x64.zip`，完整解压后运行 `PBZ-Editor.exe`。** 先退出游戏。默认用户数据、设置和备份继续保留；便携模式升级时保留 `.local`。

# v0.3.4 · Complete the Village of Lu and Mirage Estate Quick Hand chapters

Two actions are in **More**. They write only the save fields matched to these chapters. View-only categories stay view-only, and clear soul is unchanged.

- **Complete Village of Lu Quick Hand** marks branches `3` and `3-1` of `MiaoShouKongKong` completed, and adds `ljc.小张收集物.1/2/3` plus `ljc.藏身处小张.收集完奇珍异宝`. When accessories can be written and Fine Thread is missing, it adds `AC_Control`.
- **Complete Mirage Estate Quick Hand** does the same for branches `6` and `6-1`, using the `xm` tag prefix from bell `bell_xm_xiao_zhang_005`. It adds `AC_Electrified` when the Thundermoon Lantern is missing.
- `ACH_039` (Lost and Found) is appended to `__Achievements__.UnlockedIds` only after every region's branches are complete. Finishing these two chapters alone does not touch the achievement slot. The Steam popup still depends on the game reporting it, so loading the save may not show one.
- The treasure items stay in the inventory. The edit stays in the preview until you save, and saving creates a backup first. An unrecognized quest record is left unchanged.

**Download `PBZ-Editor-0.3.4-windows-x64.zip`, extract it completely, exit the game, and run `PBZ-Editor.exe`.** Default settings and backups are retained. Keep `.local` when upgrading a portable installation.
