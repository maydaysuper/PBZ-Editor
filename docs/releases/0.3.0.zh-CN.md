# v0.3.0 · 自动兼容预览版

[English](0.3.0.en.md)

游戏更新后，先让工具自己检查。兼容的部分继续使用，局部变化只暂停对应功能。

- 移除整份 EXE 必须一致的限制。自动查找密钥，用存档目录认证信息确认；支持已识别布局下的位置移动和密钥轮换。
- 物品表按类别检查属性布局和必要字段。数值或条目数量变化可以通过检查，某一类别不兼容时不会连带禁用全部物品。
- 地图、文字和图标分别回退。地图失败仍可搜索；缺失文字保留原名或 ID。
- 能完整读取的未知容器版本进入只读模式；高级添加、另存副本和恢复功能遵守相应检查。
- 打开存档后游戏文件再次更新，会暂停写入并要求重新检查。
- 中文、英文界面同步提供检测结果，不增加版本选择或强制跳过检查的步骤。

**下载 `PBZ-Editor-0.3.0-windows-x64.zip`，完整解压后运行 `PBZ-Editor.exe`。** 默认用户数据、设置和备份继续保留；便携模式升级时保留 `.local`。

已完成合成兼容场景、参考版本真实资源的内存变更检查、隔离存档文件往返和备份恢复验证。Steam build **26266538** 仍是实机参考环境，其他真实游戏版本尚未做游戏内回读验证。格式检查通过不代表所有游戏效果已验证；本版不会继承旧版的游戏回读通过标记。
