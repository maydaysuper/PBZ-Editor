# v0.3.7 · Set delivery back to not started, then talk to Zhang

v0.3.6 marked delivery in progress. This build uses the not-started shape from the public save: `EBranchType::None`, progress all zeros, timestamp `0001.01.01-00.00.00`, and that deliver branch removed from the completed list.

The same two **More** items do this, including when the chapter was already delivered:

- **Village of Lu: let Zhang take the hand-in**
- **Mirage Estate: let Zhang take the hand-in**

The collect branch stays finished. `小张收集物.1/2/3` and `藏身处小张.收集完奇珍异宝` stay, and any other collection tags already present stay too. If the quest was `QC_Succeded`, it is set back to `QC_Started`, the value unfinished quests use in the public save. `achievment.妙手拾遗.完成`, if this editor added it, is removed. `ACH_039` is not written. Crimson Forest, Pangzhen, and Meigu Lake are not rewritten. A save that is already in this state is left unchanged.

Collected-but-not-delivered was not copied from a save taken in the middle of the conversation.

Exit the game, run both items, save, then talk to **Quick Hand Zhang in Village of Lu** and **Quick Hand Zhang in Mirage Estate**. The game should finish the delivery and unlock Lost and Found. If the conversation does not start, stop. Do not change more flags.
