# v0.3.5 · 这两项也会写入妙手拾遗

[English](0.3.5.en.md)

v0.3.4 把陆家村、戏梦山庄标成完成后，成就没有出现。原因是当时只有「存档里每一个任务分支都已完成」才写入 `ACH_039`。多出来的未完成分支，或游戏保存时拿掉进度数组的已完成分支，都会让这次写入被跳过。章节已经是完成状态时再点一次，也不会补成就。

现在「完成陆家村的妙手空空」和「完成戏梦山庄的妙手空空」都会：

- 把 `ACH_039`（妙手拾遗）加进成就槽的 `UnlockedIds`。计数、已完成元素和待弹出列表不动。
- 在当前进度槽补上 `achievment.妙手拾遗.完成`。这是存档里其他已解锁成就使用的标记，拼写就是少一个 e。
- 章节已经交付过时再点一次，仍然会补上缺少的成就，不改写该分支。

不改血色森林、庞镇、梅谷湖的任务分支。待弹出列表 `PlatformPending` 在看过的存档里是空的，没有见过里面的条目，所以没有猜着写。Steam 弹窗不保证出现：游戏如果在读档时把新的 `UnlockedIds` 报给 Steam，才可能弹出，这一点没有实机验证。

**下载 `PBZ-Editor-0.3.5-windows-x64.zip`，完整解压后运行 `PBZ-Editor.exe`。** 先退出游戏。已经用 v0.3.4 交付过的存档，再点一次对应菜单然后保存即可。
