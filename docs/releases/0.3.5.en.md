# v0.3.5 · These two actions also record Lost and Found

[简体中文](0.3.5.zh-CN.md)

v0.3.4 could mark Village of Lu and Mirage Estate delivered without the achievement appearing. It wrote `ACH_039` only when every stored quest branch was already `BranchCompleted`. An extra unfinished branch, or a finished branch whose progress array the game omitted on save, skipped that write. Running the action again on an already delivered chapter did not add the achievement either.

**Complete Village of Lu Quick Hand** and **Complete Mirage Estate Quick Hand** now:

- Append `ACH_039` (Lost and Found) to `UnlockedIds` in the achievement slot. Counters, completed elements, and the pending list stay as they are.
- Add `achievment.妙手拾遗.完成` on the current progress slot. That is the marker other unlocked achievements use, including the missing letter in `achievment`.
- Still add a missing achievement when the chapter is already delivered, without rewriting that branch.

Branches for the Crimson Forest, Pangzhen, and Meigu Lake are not rewritten. `PlatformPending` was an empty list in the saves that were inspected, and no entry shape was seen, so it is left alone. The Steam popup is not guaranteed. It can appear only if the game reports the new `UnlockedIds` entry to Steam on load, and that path was not verified in-game.

**Download `PBZ-Editor-0.3.5-windows-x64.zip`, extract it completely, exit the game, and run `PBZ-Editor.exe`.** If v0.3.4 already delivered the chapter, open the same menu item again and save.
