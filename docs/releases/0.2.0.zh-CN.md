# v0.2.0 预览版

[English](0.2.0.en.md)

首个公开预览版：离线搜索与编辑物品，按分类和地图浏览，并显示本机游戏图标。背包调整、撤销与保存集中在一个界面；支持自动备份和另存副本。

- 程序内简体中文 / English 切换，保留未保存修改并记住语言选择。
- 自动检测本机游戏与存档，首次准备物品和图标后缓存。
- 完整 Windows x64 运行包，解压后双击 EXE；无需安装 Python、额外下载 DLL 或以管理员运行。
- 默认用户数据目录、可选便携模式，升级保留设置和备份。
- 开放源码解码器和明确的源代码文件清单，不含玩家存档、实际测试数据、提取的游戏资产或专有 DLL。

**玩家下载：`PBZ-Editor-0.2.0-windows-x64.zip`**。完整解压，退出游戏后运行 `PBZ-Editor.exe`。开发者可下载 `PBZ-Editor-0.2.0-source.zip`，`SHA256SUMS.txt` 用于校验两个文件。

支持 Steam build **26266538**。五类样品已通过游戏载入保存后的文件回读；并非全部物品效果已验证，药品次数仍受游戏补充规则影响。未完成干净 Windows 电脑验证。完整 [验证范围](../validation.zh-CN.md) 和 [使用说明](../../README.md)。
