# v0.3.3 · 仅可查看时写清怎么清除铸魂

[English](0.3.3.en.md)

本版不放宽添加、修改和移出，也不多写字段。清除铸魂仍然只改 `AlreadySnapSoul`：主武器为整数 `0`，影之武装为布尔 `false`。

- 主武器或影之武装因为数值结构只能查看时，选中已铸魂的物品会说明：移出保持灰色。请先完全退出游戏，点「清除铸魂」，再点右上角保存。
- 点「清除铸魂」后，预览立刻标明铸魂已清除、尚未写入。等级、时间和其他字段不变，物品仍留在背包。
- 没有铸魂时按钮保持灰色，也不会提示去点它。

**下载 `PBZ-Editor-0.3.3-windows-x64.zip`，完整解压后运行 `PBZ-Editor.exe`。** 先退出游戏。默认用户数据、设置和备份继续保留；便携模式升级时保留 `.local`。
