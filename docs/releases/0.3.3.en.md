# v0.3.3 · Explain clear soul while the category stays view-only

[简体中文](0.3.3.zh-CN.md)

This build does not relax add, edit, or remove, and it does not write any extra fields. Clear soul still changes only `AlreadySnapSoul`: integer `0` for a main weapon, boolean `false` for a phantom weapon.

- When a main weapon or phantom weapon is view-only because its numeric layout cannot be confirmed, selecting a forged item explains that Remove stays disabled. Exit the game completely, click **Clear soul**, then **Save changes**.
- After **Clear soul**, the preview says the soul forge is cleared and not saved yet. Level, timestamps, and every other field stay as they were. The item stays in the inventory.
- The button stays disabled when the item is not forged, and the note does not tell you to click it.

**Download `PBZ-Editor-0.3.3-windows-x64.zip`, extract it completely, exit the game, and run `PBZ-Editor.exe`.** Default settings and backups are retained. Keep `.local` when upgrading a portable installation.
