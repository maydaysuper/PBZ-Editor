PBZ Editor 0.3.4 — Start here
简体中文: START-HERE.txt

1. Extract the complete archive. Keep the EXE and _internal folder together.
2. Exit the game and run PBZ-Editor.exe. No Python or administrator rights needed.
3. Game and save detection is automatic. If needed, select the game root containing platform/steam/PBZ.exe.
4. Find an item → Add to backpack → Adjust values on the right → Save.
5. Switch 简体中文 / English at the top. Backups are created before saving; use Backups to view or restore them.

Runs on Windows x64. Steam build 26266538 is the tested reference; updates are checked automatically.
Incompatible categories block add, edit, and remove. A soul-forged weapon can use Clear soul: exit the game completely, then save. Search works without maps. Unverifiable saves are not written.
The first launch prepares metadata and icons from your installed game. Wait for preparation to finish.
Default data: %LOCALAPPDATA%\PBZ-Editor. Upgrade by extracting a complete new version.
Portable mode: create an empty portable.flag beside the EXE, and keep the adjacent .local data folder.
Medicine uses follow the game's refill rules. Catalog coverage does not verify every item's in-game behavior.
