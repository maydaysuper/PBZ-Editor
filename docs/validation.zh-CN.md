# 验证范围

[English](validation.en.md)

本版适配 Steam build **26266538**，测试仅使用隔离副本。公开仓库不包含实际玩家存档、原始实测报告、样品数值、私人截图或生成的游戏资源。

| 范围 | 结果与边界 |
| --- | --- |
| 自动测试 | 合成存档覆盖读写、边界、备份、外部变化拦截、未修改槽保护、界面与语言切换；可在无游戏资源的机器运行 |
| 本机资源 | 844 条目录、799 条可编辑、714 个物品图标；与本机基准比较，文字与地图信息来自已安装游戏 |
| 文件往返 | 本机副本通过修改、导出、备份、恢复与独立解码检查；验证未修改槽和无关 JSON 保留 |
| 游戏回读 | 五类样品（道具、主武器、影之武装、饰品、药品）通过载入、手动保存、退出后回读；原进度文件哈希和时间保持不变 |
| 运行包 | 本机新数据目录、中文空格路径、精简 PATH、便携模式、旧数据迁移、再次启动、升级保留备份及错误提示已检查 |
| 干净机器 | 没有独立 Windows 电脑或干净虚拟机，尚未验证 |
| GitHub 构建 | 工作流可手动运行，结果以仓库 Actions 页面为准；无游戏的 CI 不构成游戏内验证 |

## 已知限制

- 药品次数遵循装备栏与游戏补充规则。历史测试中一次载入保存曾把 1 次补为 2 次；成功回读验证的是装备栏中 2 次保留，不能承诺任意次数原样保留。
- 完整服装写入账号全局衣柜。内部头发、身体网格等资产不作为独立套装解锁；服装的游戏显示未完成逐项验证。
- 目录与存档结构支持不等于所有物品的效果、剧情、成就和获取流程都已验证。增加任务物品不自动重放任务事件。
- 部分地图关系来自游戏的调试区域清单，只代表关联；未找到关联的条目显示“区域未确定”，不猜测位置。
- 英文名称、描述与地图标签缺失时保留原始名称或 ID，避免编造翻译。
- 未签名程序可能触发 Windows 的发行者提示；请从本仓库 Release 下载并核对 SHA256SUMS.txt。不需要关闭系统防护。

运行包的 `release-manifest.json` 记录依赖、解码器和可执行文件指纹。只有本机私有验证记录与当前存档实现和解码器的指纹完全一致，构建才标记五类样品回读通过；他人或 CI 重新构建默认标记 `NOT_TESTED`。原始记录不随包发布。
